# Preset sources and scope

Source: [System Reference Document 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf).

- Guard: pages 399-400; one-handed spear.
- Goblin: page 315; scimitar.
- Skeleton: page 346; shortsword.
- Starting HP uses the given average.
- Initiative uses the listed  Dexterity modifier.
- Each preset makes one attack per turn.
- Movement, special abilities, dame-type vulnerabilities, and immunities are outside the current simulation.
- Practice Opponent is a project test fixture.
